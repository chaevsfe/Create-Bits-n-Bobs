# Create Fly: Bits 'n' Bobs

Cogwheel chains, flanged cogwheels, girder struts, nixie displays, lights, chairs, dyeable pipes and tanks, and a large tile palette.

> [!IMPORTANT]
> **This is an unofficial port.** It is not affiliated with or endorsed by
> Cake, Kipti, NormalGuy, Astral and Spydnel. 
> Please report problems here.

## Compatibility

| Component | Version |
| --- | --- |
| Minecraft | `26.3` |
| Mod loader | Fabric Loader `0.20.1` or newer |
| Create Fly | `6.0.9-1` or newer |
| Fabric API | required |
| Java | `25` or newer |
| Environments | Client and server |

## Building

```
git clone https://github.com/chaevsfe/Create-Bits-n-Bobs
cd Create-Bits-n-Bobs
./gradlew build
```

Requires JDK 25.
